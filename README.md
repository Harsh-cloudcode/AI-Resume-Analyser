# AI Resume Analyzer

An AI-powered resume analysis application that combines natural language processing, full-stack development, and AI-assisted evaluation to analyze resumes and generate personalized questions and recommendations.

## Overview

The AI Resume Analyzer allows users to upload a resume and receive an automated analysis of its content.

The application extracts text from the uploaded resume, processes the information, generates relevant questions, evaluates the user's responses, and provides AI-assisted recommendations.

The project demonstrates the integration of NLP, AI APIs, backend services, databases, and a modern web interface into a single application.

## Key Features

- Resume upload and text extraction
- Automated resume content analysis
- NLP-based text processing
- Question generation based on resume content
- Question-and-answer evaluation
- AI-assisted recommendations
- FastAPI backend
- React-based frontend
- MongoDB database integration
- Gemini API integration
- Environment-based API key management
